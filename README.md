# Deep Learning Fundamentals
Youtube Link: https://youtu.be/eVwBjaC-khE

A comprehensive, step-by-step collection of Jupyter Notebook tutorials designed to take you from the mathematical foundations of deep learning to building advanced neural networks using modern frameworks.

## 🧠 About This Repository

This repository bridges the gap between deep learning theory and practical implementation. Instead of focusing on just one framework, it provides side-by-side learning across the most popular tools in the industry, including **NumPy**, **PyTorch**, **TensorFlow/Keras**, and **JAX**.

Whether you are a beginner looking for geometric intuition or an advanced learner exploring JAX, these notebooks provide clear, runnable code examples.

## 📂 Repository Contents

The tutorials are numbered sequentially to provide a guided learning path:

### Part 1: Foundations & Intuition
Before diving into high-level APIs, understand the math and data structures that power neural networks.
* `1_numpy_foundations_for_deep_learning.ipynb` - Core matrix operations and data manipulation.
* `10_why_deep_learning_works_geometric_intuition.ipynb` - Understanding the visual and mathematical intuition behind neural networks.
* `15_numpy_foundations_for_deep_learning.ipynb` - Advanced NumPy concepts for ML.

### Part 2: PyTorch
From basic tensors to complex neural network architectures using Meta's PyTorch framework.
* `2_pytorch_tensors_from_zero_to_hero.ipynb` - Introduction to PyTorch tensors and autograd.
* `11_pytorch_neural_networks_tutorial.ipynb` - Building and training your first PyTorch models.
* `12_pytorch_advanced_tutorial.ipynb` - Advanced PyTorch techniques, custom datasets, and training loops.

### Part 3: TensorFlow & Keras
Building models using Google's ecosystem, focusing on the high-level Keras API.
* `13_keras_tensorflow_neural_networks_tutorial.ipynb` - Basics of building Sequential and Functional models in Keras.
* `14_keras_tensorflow_advanced_tutorial.ipynb` - Advanced callbacks, custom layers, and optimization techniques.

### Part 4: JAX
Exploring high-performance machine learning research using JAX.
* `16_jax_deep_learning_tutorial.ipynb` - Introduction to JAX, `jit`, `vmap`, and `grad`.
* `17_jax_neural_networks_tutorial.ipynb` - Building neural networks functionally with JAX/Flax.
